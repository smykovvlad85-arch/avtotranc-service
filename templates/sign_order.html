Подписать поручение клиенту

Здесь готовим сведения для ответа экспедитора на поручение клиента. В Контуре уже заполнены данные клиента и маршруты — их не меняем. Для этого титула не нужна загрузка XML.

01

Постоянные сведения экспедитора

Копирование в Контур

Для подписания ПЭ2 требуются номер записи в реестре экспедиторов «ГосЛог» и дата регистрации. Введи их один раз — сервис сохранит значения в этом браузере для следующих поручений.

Эти сведения сохраняются только в браузере на этом компьютере. На другом компьютере их потребуется ввести снова. Сервис не получает доступ к твоему личному кабинету или сертификату.

02

Услуги по маршрутам

Контроль заполнения

В титуле клиента маршруты уже есть. В каждой услуге маршрута нужно выбрать исполнителя в Контуре — «Моя организация» или другого участника. Галочки ниже нужны только для контроля: они не изменяют данные Контура.

Если в маршруте несколько услуг, проверь исполнителя у каждой услуги. Отдельный раздел «Общие услуги» заполняется только при наличии таких услуг.

03

Перейти к подписанию

Подпись только в Контуре

Открыть Контур ↗

Это помощник, а не интеграция с Контуром. Нажатие здесь не заполняет поля в Контуре, не сохраняет там черновик и не подписывает документ. Подпись КЭП выполняется лично в Контуре после проверки.
