# Автотранс — комплексное сопровождение перевозчиков

Статический одностраничный сайт для GitHub Pages.

## Файлы
- `index.html` — главная страница сайта
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages

После загрузки файлов в корень репозитория:
1. Откройте Settings → Pages.
2. Source: Deploy from a branch.
3. Branch: `main`, папка `/ (root)`.
4. Сохраните настройки.

Для подключения собственного домена позже можно добавить файл `CNAME`.
